# nulo ipse dixit
Multiple Wallet Statements Cost basis Comptometer for [luno.com](https://www.luno.com/).

### How do I download my wallet statement?
1. [Sign in to your Luno](https://www.luno.com/login) account on the web
2. Select [Portfolio](https://www.luno.com/wallet/accounts)
3. Select the wallet you'd like to download a statement for
4. Scroll all the way to the bottom and select **DOWNLOAD STATEMENT**
5. Select a **Begin date** and an _End date_, choose **CSV format**, and select **CREATE STATEMENT**
6. Scroll down to the **Statements** section and select **DOWNLOAD** to get your statement
