# nulo ipse dixit
Multiple Wallet Statements Cost basis Comptometer for [luno.com](https://www.luno.com/).

### How do I download my wallet statement?
1. Sign in to your [luno.com](https://www.luno.com/login) account on the web
2. Select [Portfolio](https://www.luno.com/wallet/accounts)
3. Select the wallet you’d like to download a statement for
4. Scroll all the way to the bottom and select _DOWNLOAD STATEMENT_
5. Select a _Begin date_ and an _End date_, choose _CSV format_, and select _CREATE STATEMENT_
6. Scroll down to the _Statements_ section and select _DOWNLOAD_ to get your statement
